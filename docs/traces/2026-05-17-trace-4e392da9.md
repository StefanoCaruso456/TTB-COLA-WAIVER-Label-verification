## Why the model swap did not land

PR #25 changed the code default in `lib/services/extraction-service-factory.ts:18`:

```ts
model: env.GEMINI_MODEL ?? "gemini-2.5-flash-lite",
```

The factory falls back to `gemini-2.5-flash-lite` **only when `GEMINI_MODEL` is unset**. Railway's service Variables panel still has `GEMINI_MODEL=gemini-2.5-flash`, so the env var wins and the code default never fires. The trace confirms this directly: `metadata.model = "gemini-2.5-flash"`.
